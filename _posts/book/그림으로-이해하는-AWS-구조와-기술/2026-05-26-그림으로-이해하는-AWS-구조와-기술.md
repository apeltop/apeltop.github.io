## 휴일 오후, 커피 한 잔과 함께

석가탄신일 휴일을 맞아 여유롭게 커피 한 잔 내려놓고 펼쳤는데, 그림과 함께 폭넓은 내용을 다루고 있어 어느새 끝까지 읽고 있었습니다.

사실 길벗의 「그림으로」 시리즈는 대부분 구매해서 보고 있는데요, 얇지만 필요한 내용을 컴팩트하게 담고 있다는 점이 가장 큰 매력입니다. 이번에 마침 리뷰어에 선정되어 AWS 편을 만나볼 수 있어 더없이 반가웠습니다.

## 어떤 책인가

> "읽는 것만으로 충분하다! 쉽고 빠르게 이해하는 AWS 개념과 서비스"

AWS 리소스 하나하나를 그림과 함께 가볍게 설명해주는 구성이라 술술 읽히는 책입니다. EC2, S3, VPC, RDS 같은 핵심 서비스부터 컴퓨팅·네트워크·보안의 기본 개념까지, 226개의 일러스트와 함께 100개가 넘는 AWS 서비스를 다룹니다.

코드를 따라 치며 실습하는 핸즈온 책이 아니라, **"AWS가 어떤 구조로 동작하고 각 서비스가 무슨 역할을 하는지"** 큰 그림을 잡아주는 개념서에 가깝습니다. 그래서 처음 AWS를 접하는 분께는 길잡이가 되고, 이미 실무에서 쓰고 있는 분께는 흩어져 있던 지식을 한 번에 정리해주는 역할을 합니다.

## 개정2판에서 달라진 점

초판(2021)이 EC2·S3·VPC·RDS 중심의 8개 장이었다면, 개정2판은 최근 몇 년간의 클라우드 트렌드를 반영해 **11개 장으로 확장**되었습니다.

- **생성형 AI / 머신러닝 강화** — Amazon Bedrock, Amazon SageMaker, 그리고 관리 콘솔을 돕는 Amazon Q까지 별도 장으로 정리
- **데브옵스 / 컨테이너 / 서버리스** — ECS·EKS, Lambda, API Gateway, Step Functions, CI/CD(CodeBuild·CodeDeploy·CodePipeline) 등 현대적인 운영 방식 보강
- **데이터 분석 서비스** — Kinesis, Glue, Redshift, Athena, QuickSight 등 데이터 파이프라인 영역 신설
- **IoT 서비스** — AWS IoT Core를 중심으로 한 IoT 구성 추가

생성형 AI와 데이터 분석이 AWS의 핵심 축으로 들어온 지금, 이런 최신 서비스들을 입문서 수준에서 그림으로 짚어준다는 점이 개정판의 가장 큰 가치라고 느꼈습니다.

## 목차

**1부 · AWS 기초 지식**

1. **아마존 웹 서비스 기초 지식** — AWS란 무엇인가, 매력, 서비스 분류, 비용 구조, 도입 사례와 마음가짐
2. **AWS를 이해하기 위한 클라우드 환경의 구조** — 시스템 구축 기초, 서버와 하드웨어, 클라우드와 온프레미스, SaaS/PaaS/IaaS, 가상화와 분산 처리
3. **AWS를 사용하기 위한 도구** — 관리 콘솔, 매니지드 서비스, IAM과 접근 권한, 요금 계산(Billing), Amazon Q와 AWS CLI, CloudWatch, 리전과 가용 영역

**2부 · AWS 주요 서비스**

4. **컴퓨팅 서비스** — Amazon EC2, 인스턴스 생성과 서버 설계, AMI, 인스턴스 유형, EBS, 스냅샷, SSH와 키 페어, IP 주소와 Elastic IP
5. **스토리지 서비스** — Amazon S3, 객체와 버킷, 버킷 정책, 스토리지 클래스, 정적 웹사이트 호스팅, 버전 관리·수명 주기·복제
6. **데이터베이스 서비스** — RDB와 NoSQL 개념, Amazon RDS, Amazon Aurora, 키-밸류형·문서형 데이터베이스
7. **네트워크와 보안** — Amazon VPC, 서브넷·라우팅·NAT, 인터넷 게이트웨이, ELB와 Auto Scaling, Route 53, CloudFront, 보안 그룹, AWS WAF, GuardDuty

**3부 · 한 단계 더 나아가기**

8. **데브옵스 / 컨테이너 / 서버리스** — ECS·EKS, AWS Lambda, API Gateway, EventBridge, Cognito, Step Functions, SQS/SNS, CloudFormation, CodeBuild·CodeDeploy·CodePipeline
9. **머신러닝과 생성형 AI 관련 서비스** — Amazon Bedrock, Amazon SageMaker, API로 사용하는 머신러닝 서비스(Transcribe·Polly·Translate·Rekognition 등)
10. **데이터 분석 서비스** — Amazon Kinesis와 Data Firehose, AWS Glue, OpenSearch Service, QuickSight, Redshift, Athena
11. **IoT 서비스** — IoT 개념, AWS IoT Core, IoT Core와 조합하는 서비스

## 읽으면서 느낀 점

이미 알고 있는 내용이라도 새롭게 챙겨갈 팁들이 곳곳에 숨어 있어서, 책 읽는 시간이 늘 아깝지 않다는 걸 다시 한 번 느꼈습니다.

특히 그림과 함께 서비스 간의 관계를 설명해주는 부분이 좋았습니다. 실무에서 단편적으로 쓰던 서비스들이 "전체 아키텍처 안에서 어디에 위치하는지" 한눈에 정리되는 경험이었습니다. 한 챕터가 길지 않아 출퇴근길이나 짬이 날 때 한 절씩 끊어 읽기에도 부담이 없었습니다.

## 누구에게 추천하나

- **AWS를 처음 접하는 분** — 용어와 서비스의 전체 지도를 그리고 싶을 때
- **자격증(SAA 등)을 준비하는 분** — 서비스 개요를 그림으로 빠르게 훑고 싶을 때
- **실무에 익숙한 분** — 생성형 AI·데이터 분석 같은 새 영역을 가볍게 복습하고 싶을 때

AWS를 처음 접하시는 분들께도, 익숙하신 분들의 가벼운 복습용으로도 좋은 책이라 자신 있게 추천드립니다 👍
